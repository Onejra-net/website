# Onejra Publications — GitHub Pages

A minimal split-view Markdown archive matching the Onejra dark navy and pale blue visual style.

- Left column: **THE ARCHIVE / Published works**, search, sorting, and publication list.
- Right column: selected article content.
- Loads Markdown files from the repository through the GitHub Contents API.

## Configure

The source folder is configured in `assets/app.js`:

```js
const FOLDER = "acticles";
```
